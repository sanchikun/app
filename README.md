# デイトレ検証

月間でプラスになるかを確かめる、株デイトレードの検証アプリです。過去データでのバックテストと、実際の値動きを使った仮想売買（ペーパートレード）ができます。**実際の発注は行いません。**

> 利益を保証するものではありません。バックテストやペーパートレードの成績が良くても、実際の取引で同じ結果になるとは限りません。

## 主な機能

- **バックテスト**：過去の分足で戦略を走らせ、日次損益、目標達成日数、勝率、最大ドローダウンなどを出します。
- **ペーパートレード**：場中に毎分動き、新しく確定した1分足で仮想売買して結果を記録します。
- **安全ルール**：日次損失上限で停止、取引回数の上限、大引け前の強制決済、同時保有は1ポジションまで（持ち越しの戦略を選んだときだけ、大引けで買って翌朝まで持ちます）。
- **画面**：今月の損益、今日の損益、月次・日次損益、取引履歴、バックテストの実行、開始・停止。

## 使い方

### コマンドラインでバックテスト

```bash
npm run backtest -- 7203                                  # 5分足 × 60日、寄り付きレンジ突破
npm run backtest -- 7203 --strategy vwap --slippage 0
npm run backtest -- 7203 --interval 1m --range 7d
npm run backtest -- 7203 --strategy gapfade --loss-limit 3000   # 戦略は orb / vwap / momentum / gapfade / pullback
npm run backtest -- 7203 --entry limit --limit-wait 3     # 新規を指値にする

```

### 安寄り買い（`gapopen`）

前日終値より1%以上安く寄った銘柄を寄り付き（寄成）で買い、寄り値から0.5%下げたら損切り、そうでなければ大引け（引成）で売ります。日足10年分の検証で、前半・後半とも優位性が残った唯一のルールです。

寄り付きと大引けの値は分足に入っていない日が多いので、この戦略だけは日足の値（始値・安値・終値）で動きます。バックテストは日足で行い、ペーパートレードも当日の日足を毎分取りにいって、寄り付きでの買い、安値での損切り、大引けでの決済を判定します。対象銘柄のうち条件に合うものが複数あれば、ギャップが最も大きい1銘柄だけを買います。

```bash
npm run backtest -- 7203,6758,8306 --strategy gapopen --loss-limit 3000      # 日足 × 10年
npm run backtest -- core --strategy gapopen --loss-limit 3000 --max-position 500000  # 既定の50銘柄（wide で他の約200銘柄、all で両方）
```

実際の取引と違う点があります。寄り値は寄り付くまで分からないので、実際には寄り前の気配で「1%以上安く寄るか」を判断することになり、外れる日があります。急落時の損切りは1ティックより大きく滑ることがあります。

### 上げた日の持ち越し（`overnight`）

場中（始値から終値）に2%以上上げた銘柄のうち、最も上げた1銘柄を大引け（引成）で買い、翌営業日の寄り付き（寄成）で売ります。日足10年分の検証では、株の値上がりは場中ではなく夜間に集中していて、上げた日の翌朝はとくにその傾向が強く出ました。

デイトレではなく、夜間に持ち越します。**損切りは置けません。**夜間に悪材料が出ると翌朝の寄り付きでそのまま損になるので、`overnightMaxPositionYen` で買付金額を小さく抑えてください。1日の損失上限は損切りには効きませんが、翌朝の決済で上限を超える損が出た日は、その日の新規の買いを止めます。配当落ち日をまたいだときは、配当を損益に含めます。

`gapopen_overnight` にすると、安寄り買い（9:00〜15:30）と持ち越し（15:30〜翌9:00）の両方を動かします。持つ時間が重ならないので、同時に持つのは1ポジションのままです。

```bash
npm run backtest -- core --strategy overnight --overnight-max-position 300000
npm run backtest -- core --strategy gapopen_overnight --loss-limit 3000 --max-position 500000 --overnight-max-position 300000
```

実際の取引と違う点があります。引成の注文は大引けの前に出すので、「2%以上上げたか」の判断は 15:20 ごろの値で行うことになります。検証とペーパートレードは確定した終値で判断しています。決算発表の日をまたぐかどうかは見ていません。

### 追加で確かめたこと（2026年11月、260銘柄 × 10年の日足）

「確実に勝てる」ルールは見つかっていません。下の2つは、期間や銘柄群を分けても優位性が残った候補で、ペーパートレードで続くかを確かめる段階です。

**1. 2日続けて下げた安寄りだけを買う（`gapPrevDropPct`）**

前日に2%以上下げ、今朝さらに1%以上安く寄った銘柄だけを買います。条件なしの安寄り買いと比べて、10年の合計はほぼ同じ（+48万円と+52万円、100株・損失上限3,000円・買付上限50万円）ですが、取引は3分の2、最大ドローダウンは約半分（-5.4万円と-9.6万円）、最悪の月は -1.5万円（条件なしは -2.5万円）でした。ギャップと前日下落の境目を 0.5〜2%、1〜3% に動かしても同じ向きの結果です。既定の50銘柄だけでは差がはっきりせず、効いているのは主にそれ以外の銘柄です。

```bash
npm run backtest -- all --strategy gapopen --gap-prev-drop 2 --loss-limit 3000 --max-position 500000
```

**2. TOPIX連動ETFを月曜の引けで買い、火曜の寄りで売る（`overnightWeekdays`、`overnightSymbols`）**

「上げた日の持ち越し」の成績は、ほとんどが相場全体の夜間の上昇そのものでした。全銘柄を毎晩持ち越した場合と比べた上乗せは、2023年以降ほぼゼロです。それなら個別株ではなく指数のETFを持ち越すほうが、決算などの個別の悪材料を避けられます。

曜日で分けると、夜間の上昇は月曜の引けから火曜の寄りに集中していました。TOPIX連動ETF（1306）で1晩あたり平均 +0.16%（t値 3.9、勝率58%）、2020〜2026年は7年続けてプラスです。ただし 2018年はマイナス、2019年はゼロで、理由も分かっていません。木曜の引けで買う夜は、直近6年マイナスでした。

```bash
npm run backtest -- 1306 --strategy overnight --overnight-min -100 --overnight-weekdays 1 --shares 700 --standard-tick
npm run dailystudy -- --symbols 1306,1321      # 曜日ごとの夜間の成績
# 安寄り買い（個別株）と、ETFの月曜持ち越しを両方動かす
npm run backtest -- all --strategy gapopen_overnight --gap-prev-drop 2 --overnight-symbols 1306 --overnight-min -100 --overnight-weekdays 1 --overnight-shares 700 --loss-limit 3000 --max-position 500000
```

1306 を700口（約28万円）で10年：458回、合計 +13.3万円、プラスの月 66%、最大ドローダウン -1.8万円、最悪の1晩 -5,390円。損切りは置けません。

**そのほか分かったこと**

- 安寄り買いで「ギャップが最も大きい1銘柄」を損切りなしで持つと、優位性はほぼ消えます（t値 0.8）。0.5%の損切りがあって初めて成り立つルールです。
- 安寄り買いは 2017〜2019年にはほとんど効いておらず、2020年以降に出てきた傾向です。なくなることもあり得ます。
- 検証した銘柄は「今も上場している大型株」を手で選んだものなので、成績は実際より良く出ます。ETFの結果にはこの偏りがありません。
- 約130通りの条件を試しています。t値が3を少し超える程度の結果は、偶然でも出ます。

### ルール探しの続き（作業台と答え合わせ）

`scripts/lab*.ts` は、新しいルールの当たりを付けるための作業台です。日足（出来高つき）、ETF、米国の指数、VIX、ドル円を `.cachev` に保存し、条件ごとに日平均の成績、相場平均に対する上乗せ、3つの期間ごとの t値を出します。

```bash

npx tsx scripts/lab-round4.ts       # 上のETFのルールを年ごとに
npx tsx scripts/lab-round5.ts       # 業種ごとの動き、暦（SQ・権利落ち・月末月初・曜日）
npx tsx scripts/lab-round6.ts       # 日経平均・ドル円の状態、損切り・利確の置き方
npx tsx scripts/lab-fetch5m.ts      # 5分足 × 60日（10分ほど）
npx tsx scripts/lab-dip.ts          # 押し目の指値が、最初に約定した1銘柄でも成り立つか
npx tsx scripts/lab-ampm.ts         # 前場と後場の関係
npx tsx scripts/lab-stop.ts         # 損切りの滑りを変えたときの成績、5分足で見た損切りの時刻
npx tsx scripts/lab-probe.ts        # 全コードの売買代金を調べる（8分ほど）。銘柄を広げる下調べ
npx tsx scripts/lab-fetch-wide.ts   # 広げた銘柄の日足を .cachew に取得（5分ほど）
npx tsx scripts/lab-wide.ts         # これまでの260銘柄と、使っていない銘柄群で同じルールを比べる
npx tsx scripts/lab-monday.ts       # 月曜の持ち越しがなぜ高いか（米国の曜日、先物の1時間足、祝日の週）
npx tsx scripts/lab-top3.ts         # 安寄り買いを1日に複数銘柄へ分けた場合（100株単位、円で試算）
npx tsx scripts/lab-multi.ts        # 2銘柄×25万円の作り込み（選び方、ギャップの範囲、損切り幅、絞り込み）
npx tsx scripts/lab-short.ts        # 空売り（高く寄った銘柄を売って引けで買い戻す）
npx tsx scripts/lab-fetch1m.ts      # 1分足 × 7日（3分ほど）
npx tsx scripts/lab-open.ts         # 寄りで買えなかったら／寄り付きから5分間の損切り（5分足・1分足）
npx tsx scripts/lab-fetch1h.ts      # 1時間足 × 2年（3分ほど）
npx tsx scripts/lab-open1h.ts       # もうけが1日のどこで出ているか、10時に売る場合（1時間足2年）
NODE_USE_ENV_PROXY=1 npx tsx scripts/lab-jquants-fins.ts   # 決算などの開示日を取得（J-Quants、1時間ほど）
npx tsx scripts/lab-earnings.ts     # 安く寄った理由が決算かどうかで分ける
npx tsx scripts/lab-fetch-topix.ts  # TOPIX500 の残り235銘柄の日足を .cachet に取得（3分ほど）
npx tsx scripts/lab-topix.ts        # TOPIX500 の残りの銘柄と、TOPIX500 全体での成績
npx tsx scripts/lab-preopen.ts      # 寄り付く前に銘柄を決めて指値（寄指）を出す形
npx tsx scripts/lab-exit.ts         # 売る時刻・損切りの置き方・曜日を、ためてある5分足で見る
npx tsx scripts/lab-monday-etf.ts   # 月曜の持ち越しをETFごとに比べる
npx tsx scripts/lab-plan.ts         # 切り替え後の形で、判断に要る期間・最悪の時期・税引き後の手取り
```

候補のルールと境目は 2026-11-19 に固定してあります。`lab-forward.ts` はそれより後の日足だけで成績を数えるので、日がたってから動かすと、選び方の偏りがない成績が分かります。

**2巡目で残った候補（2026年11月）**

- **候補3：米国が大きく動いた翌日は、逆向きのETFを寄りで買って引けで売る。** S&P500 が前日 +1.5%以上なら日経ダブルインバース（1357）、-2%以下なら日経レバレッジ（1570）。10年で218回、1回平均 +0.48%、t値 3.3、勝率58%。1357 の側は9年のうち8年がプラスですが、利益の4割は2020年です。年に十数回しかなく、値動きが2倍の商品なので1回で -7% もありました。候補1・2より確度は低いです。
- **候補1b：VIX が15未満の日は安寄り買いを見送る。** VIX 15未満の日の安寄り買いは10年で平均ほぼゼロでした（592日）。2017〜2019年に効かなかった理由の一部はこれで説明できます。ただし2018年は VIX が高い日でもマイナスです。

**試して捨てたもの**

- **押し目の指値（寄り値の1〜3%下に買い指値）**：日足では日平均 +10〜20bp、t値 7〜10 と一番良く見えましたが、5分足で「最初に約定した1銘柄」を取ると優位性は消えました。多くの銘柄が同時に約定する下げ相場の日に負けるためです。
- **出来高**：前日の出来高が多い・少ないで分けても、安寄り買いにも持ち越しにも使える差は出ませんでした。
- **急騰・急落した銘柄を数日持つ**：前日 ±5%、出来高3倍などは、相場平均との差がほぼゼロでした。20日で +20%以上上げた銘柄を10日持つと上乗せが出ますが、デイトレードではなく、持つ期間が重なるので t値は割り引いて見る必要があります。
- **前場と後場の関係**（前場の上げ下げ、最初の30分、昼休みのギャップ、15時までの騰落）：60日分では、はっきりした傾向は出ませんでした。

**5巡目（2026-11-19）：業種ごとの動きと暦**

銘柄を手で14業種に分け、「同じ業種のほかの銘柄」と比べました。暦は SQ、権利落ち、月末月初、曜日、連休の前後です。ここまでで試した条件は約350通りです。答え合わせ（`lab-forward.ts`）は固定した当日なので、まだ0日です。

- **残った候補（候補1c）：安寄りが「自分だけ」のときに買う。** 同じ業種のほかの銘柄より1%以上安く寄った銘柄は、場中に戻りやすい傾向がありました（全取引の日平均 +13bp、相場平均への上乗せの t値 11、3期間とも同じ向き）。逆に、業種ぐるみで安く寄った銘柄の安寄り買いは10年で平均ほぼゼロです。ただし1日1銘柄・損切り0.5%で数えると差は小さくなります。候補1に「業種より1%以上安い」を足すと 1回平均 +21bp → +24bp（t値 4.7 → 5.0、日数は1割減）で、境目を1.5%、2%にしても同じ向きです。2017〜2019年が弱いのは変わりません。確定ではなく候補です。
- 注意点：業種の寄り値は、ほかの銘柄が寄り付くまで分かりません。また、日足の始値に誤りがあると「安く寄って戻った」ように見えるので、この系統の結果は良く出やすいです。答え合わせの対象には入れていません（固定したルールは変えないため）。
- **弱い観察：木曜の候補1は10年で平均マイナス**（322日、-5bp。10年のうち6年がマイナス）。5つの曜日から後で選んだものなので、偶然の可能性が高いです。

**5巡目で捨てたもの**

- **業種の強弱の持ち越し・逆張り**：前日や5日間に強かった（弱かった）業種を翌日買っても、場中・前日比とも相場平均との差はほぼゼロ。強い業種の夜間持ち越しは境目1%でだけ良く見え、1.5%・2%で消えました。
- **業種内の出遅れ・先走り（前日の動き）**、**業種別の安寄り買い**：使える差なし。業種ごとの差は期間で入れ替わります。
- **SQ（当日・前日・翌日・週）、月末月初、連休の前後**：場中も夜間も安寄り買いも、3期間で向きがそろいません。月初の候補1は良く見えますが 2017〜2019年はマイナスです。
- **権利落ち**：権利付き最終日から権利落ち日への持ち越し（配当込み）は +34bp ですが t値 2.3、年に数日しかなく、期間ごとに弱まっています。

**6巡目（2026-11-21）：日経平均・ドル円の状態と、損切り・利確の置き方**

日経平均は前日の引けまで、ドル円は寄り付き前までの値だけを使いました。ここまでで試した条件は約550通りです。答え合わせは1営業日分（11/20）だけで、候補1は1回・損切り（-0.53%）、候補3b（米国急落の翌日に 1570）は1回・-3.4% でした。1日では何も言えません。

- **残った候補（候補1d）：相場が弱いときほど候補1が効く。** 日経平均が25日線より下の日の候補1は、1日1銘柄・損切り0.5%で 607日、1回平均 +34bp（t値 4.2）、3期間とも +25 / +33 / +40bp。25日線より上の日は 901日、+12bp（-6 / +16 / +17bp）で、2017〜2019年の弱さはほぼこちら側です。境目を25日線の -2%〜+2% に動かしても、「日経が5日で2%以上下げた」に替えても同じ向きで、年ごとでも9年のうち7年は下の日のほうが良い結果でした。ただし2つの差そのものの t値は約2.4 で、約550通り試した中では偶然でも出る大きさです。VIX 15以上（候補1b）と重なる日が多く、別々の発見ではありません。確定ではなく候補で、答え合わせの対象にも入れていません。
- **損切りの幅は、候補1では成績をあまり左右しない。** 0.2%〜3%、損切りなしのどれでも 1回平均 +16〜+32bp（t値 3.9〜4.7）でした。損切りなしが平均は一番高いですが、落ち込みは約1.6倍になります。条件なしの安寄り買いは、これまでどおり損切りが 0.6% 以下でないと成り立ちません。候補1の損切りは「もうけの源」ではなく「落ち込みを抑える道具」です。
- **弱い観察：損切りをギャップの大きさに合わせる**（ギャップの 0.25〜0.5 倍。2%安く寄ったら 0.5〜1%）と、+25〜29bp（t値 4.7〜5.2）で固定 0.5% より少し良く、2017〜2019年も +10〜18bp でした。差は小さく、1日の損失上限 3,000円とぶつかるので、設定は変えていません。

**6巡目で捨てたもの**

- **利確を置く**：損切り 0.5% と利確の両方に届いた日の順番が日足では分からず、「損切りが先」なら大きくマイナス、「利確が先」なら大きくプラスで、判定できません（候補1は 74% の日に損切りにかかります）。順番の問題がない「損切りなし＋利確」は、利確なしより悪くなりました（+1%で +11bp、+3%で +25bp、利確なしは +33bp）。置く理由は見つかっていません。確かめるなら5分足が要ります。
- **ドル円**：円高・円安の日に輸出株と内需株を分けても、相場平均との差は出ません。候補1を円の動きで分けても日数が少なく、向きがそろいません。

- **日経平均とTOPIXの差の戻り**（前日に日経ETFがTOPIX ETFより弱かった翌日）：2022年まではありましたが、2023年以降は消えています。
- **日経平均先物の夜間の値**は取得していません。寄り付きのギャップがその結果なので、すでに使っている情報と同じとみなしました。

**月曜の持ち越しの正体（2026-11-21）**

**寄り付きの現実性（2026-11-21）**

安寄り買いのもうけは、**ほぼすべて寄り付きから数分〜1時間のあいだに出ています**。寄りの板寄せで買えなければ、優位性は残りません。

- **5分遅れて買うと消える。** 5分足60日（1%以上安く寄った2,772件）で、寄り値で買うと日平均 +17.8bp（t値 2.8）、9:05 ごろ成行で買うと -2.3bp、9:10・9:30・10:00 でもゼロ前後。寄り値から 9:05 までに平均 +16.4bp 戻っていて、9:05 から引けまでは +2bp しかありません。9:05 の時点の値（寄り値より上か下か）で選んでも変わりません。
- **1時間足2年（27,402件、717日）でも同じ。** 寄り→10時 +15.8bp（t値 5.4）、10時→引け -1.1bp。前半・後半とも同じ形です。高く寄った銘柄の売りも、もうけは最初の1時間に集中しています。
- つまり実際に取引するには、寄り付く前の気配を見て、9:00 より前に寄成（または指値）の注文を出す必要があります。Yahoo Finance のデータでは寄り前の気配が分からないので、「気配で選んだ銘柄が実際に安く寄るか」は検証できていません。ペーパートレードは「寄り値で買えた」前提のままです。

寄り付きから5分間について（9:00 の足がある33日、433件）。

- 損切り0.5%にかかる銘柄の3分の2は、最初の5分でかかります。その5分間の安値は、損切りの値より中央値で41bp 下でした。1ティックは平均2.3bp なので、最悪の値で売れた場合は十数ティックの滑りに当たります。実際の約定はこのあいだのどこかです。
- 最初の5分で損切りにかかった銘柄の約半分は、5分後には損切りの値より上に戻っています。
- 1分足で 9:00 から見られたのは1日・13件だけでした（Yahoo Finance の1分足も、9:00〜9:05 が入るのは主に週の最初の営業日）。結論を出せる数ではありません。

この2つの対策（損切りは 9:05 から、10:00 に売る）は、2026-12-19 の2銘柄への切り替えと同時に本番へ入れる予定です（`gapStopFrom`、`gapExitAt`）。同じ売り方を5分足60日で試すと、上位2銘柄×25万円の合計は +7.7万円 → +5.8万円、最大の落ち込みは -1.9万円 → -1.5万円、最悪の日は -2,542円 → -4,540円でした。成績を上げるためではなく、測れない寄り付き直後の損切りに頼らないための変更です。

対策として試したこと。

- **損切りを 9:05〜9:30 から有効にする**：成績は落ちません（60日、+15〜25bp）。寄り付き直後の約定に頼らなくて済みます。
- **引けまで持たず10時に売る（候補7）**：上位2銘柄×25万円・損切り0.5%で、2年の合計は +46.5万円 → +62.3万円、t値 4.2 → 6.2、最大の落ち込みは -4.4万円 → -2.5万円。持つ時間が短いぶん危険が減ります。2年分しかなく、ルールを見つけた期間と重なっている点に注意。

### 分足をためる

Yahoo Finance の分足は、5分足が直近60日、1分足が直近7日で消えます。場中のルール（売る時刻、損切りの置き方、寄り付き直後の値動き）を長い期間で確かめられるよう、週に1回 `data/intraday/` に保存しています（週次の定期作業が実行します）。

```bash
npm run archive                        # 5分足は直近1か月、1分足は直近7日を取りにいき、まだない日だけ保存する
npm run archive -- --range5m 60d       # しばらく動かせなかったとき
```

| 場所 | 中身 |
| --- | --- |
| `data/intraday/5m/YYYY-MM-DD.csv.gz` | その日の5分足（260銘柄とETF、9:00〜15:30） |
| `data/intraday/1m-open/YYYY-MM-DD.csv.gz` | その日の1分足のうち 9:00〜10:00 |

1行は「銘柄,時刻(UNIX秒),始値,高値,安値,終値,出来高」です。1日1ファイルで、一度書いた日は書き換えません。銘柄の8割以上がそろわない日は保存せず、次回また取りにいきます。大きさは1週間で約1.5MB（1年で約80MB）です。5分足は 2026-08-24 から、1分足は 2026-11-12 からあります。

- 1分足は7日で消えるので、1週間あくとその週の分は取り戻せません（5分足は60日以内なら取り戻せます）。
- 9:00〜9:05 の足が入っているのは、主に週の最初の営業日だけです（Yahoo Finance の側の欠け）。
- 検証スクリプトからは `scripts/lab.ts` の `readArchive("5m")`、`readArchive("1m-open")` で読めます。`lab-open.ts` はためた分と取得したばかりの分を合わせて使います。

### 銘柄選びの検証

複数銘柄でバックテストを回し、寄り付きレンジが確定した時点で分かる指標（ギャップ、出来高比、レンジ値幅など）とその日の損益の関係を集計します。境界は期間の前半で3等分して決め、後半にもそのまま当てはめるので、指標の選別力が続くかどうかを見られます。

```bash
npm run screen                                    # 既定の50銘柄、5分足 × 60日、寄り付きレンジ突破
npm run screen -- --symbols 7203,6758,9984        # 銘柄を指定
npm run screen -- --loss-limit 3000 --max-stop-fit 1   # 損切りが損失枠で狭められる日を集計から外す
npm run screen -- --cache .cache --csv out.csv    # 取得した足を保存して再利用、銘柄×日の明細を書き出す
```

既定の銘柄はすべて TOPIX500 構成銘柄（細かい呼値）として計算します。株価が呼値の刻みに乗らない日（株式分割より前の調整済みの値など）は自動で除きます。

### ギャップ埋めを日足で検証

分足は60日分しか取れないので、ギャップ埋め（安く寄った日に始値で買い、前日終値への戻りを狙う）は日足で10年分を検証できます。同じ日の取引は連動するので、日ごとにまとめた平均と t 値も出します。

```bash
npm run gapstudy                          # 既定の50銘柄、10年、ギャップ1%以上
npm run gapstudy -- --range 5y --gap 2 --slippage 0
```

### 日足でルールをまとめて検証

前日までの日足と当日の始値だけで入るかどうかが決まり、当日の終値で手仕舞うルールを、10年分の日足でまとめて試します（安く寄った日の買い、前日の急落後の買い、前日高値・安値の突破、前日安値への指値買いなど）。多くのルールを一度に試すとどれかは偶然よく見えるので、期間を前半と後半に分け、両方で t 値が大きいものだけを見ます。

```bash
npm run dailystudy                         # 既定の50銘柄、10年
npm run dailystudy -- --universe wide      # それ以外の東証プライムの主な約210銘柄（all で両方）
npm run dailystudy -- --detail fade-low    # 1つのルールを年ごと、相場全体の寄り付き別、月次で見る
npm run dailystudy -- --split 2020 --notional 500000
```

「持ち越し」と付くルールは、大引けで買って翌朝の寄り付きで売ります（デイトレではなく、夜間の値動きを取りにいく形）。買う日の終値までの情報だけで判断します。

寄り付きと大引けは成行（寄成・引成）で板寄せの値段で約定するとみなし、滑りを加えません。逆指値で入るルールは滑りを1ティック加え、指値で入るルールは値が指値を1ティック以上抜けた日だけ約定とします。

`--detail` では損切り（約定値から 0.5〜3%）を入れた場合と、1日1銘柄だけ取引したときの月次の試算も出します。寄り付きや指値で入るルールは、約定が必ずその日の安値より前なので、日足でも損切りを正しく判定できます。

「前日安値に指値で買い」は、日足で数えた約定が5分足でも確認できるか、約定の時刻や順番で成績が変わるかを直近60日で確かめられます。

```bash
npm run fadecheck
```

### ペーパートレード

画面の「開始する」を押すか `POST /api/bot/start` を呼ぶと、平日 9:00〜16:59（JST）に毎分動きます。対象銘柄や金額は `PUT /api/settings` で変えます。

安寄り買いは、株価を1分に15銘柄ずつ順に取りにいきます（Cloudflare Workers は1回の実行で使える CPU 時間と外部リクエスト数に上限があり、30銘柄ずつだと CPU 時間が上限の2倍近くになったため）。株価は約20分遅れで届くので、1銘柄も届いていないあいだは2銘柄だけ様子を見て、届き始めてから15銘柄ずつ取ります。全銘柄の寄り値がそろうか 10:15 を過ぎるまで判断を待ち、そろった時点でギャップの大きい順に寄り値で買ったものとします。500銘柄なら寄り値が届き始めてから33分ほどかかりますが、買値は寄り値のままなので成績は変わりません（売りの判定も、分足を寄り付きからさかのぼって行います）。持ち越しで `overnightSymbols` を空にしたときは、`symbols` の先頭30銘柄だけが対象になります。

| `overnightWeekdays` | `[]` | 持ち越しで、大引けで買う曜日（1 = 月曜 … 5 = 金曜）。空ならどの曜日でも買う |
| `overnightSkipUsHolidays` | false | 持ち越しで、米国の株式市場が休みの日（その夜に米国市場が開かない日）は買わない。祝日は決まった規則で判定し、臨時の休場は入っていない |
| `overnightSymbols` | `[]` | 持ち越しの対象銘柄（最大20）。空なら `symbols` と同じ。ここだけにある銘柄は安寄り買いの対象にしない |

## 約定の考え方

バックテストとペーパートレードは同じエンジン（`src/core/engine.ts`）を使います。

- シグナルは足の確定時に出て、**次の足の始値**で約定します。未来の値は見ません。
- 損切りと利確は足の高値・安値で判定します。同じ足で両方に届いたときは損切りを優先します。
- 新規・損切り・強制決済は成行として滑りを加えます。利確は指値として滑りなしです。
- `entryOrder` を `limit` にすると、新規はシグナルが出た足の終値に指値を置きます。以降の足がその値を1ティックでも抜けたら指値の値段で約定とみなし、同値に触れただけでは約定としません。約定した足では利確を判定しません。
- 板の厚さや約定の順番待ちは再現していません。実際より有利に出ることがあります。

## 注意点

- 株価は Yahoo Finance の非公式APIから取ります。東証の値は約20分遅れで、予告なく使えなくなることがあります。ペーパートレードは遅れた足を順に処理するので、結果は記録として正しくても表示は約20分遅れます。
- Yahoo Finance の5分足は、9:00〜9:05 の足と 15:25〜15:30 の足が欠けている日が多くあります（9:00 の足があるのは主に週の最初の営業日）。欠けた日は寄り付きと大引けの値が分からず、寄り付きレンジは 9:05 からの足で作られます。`gapfade` は 9:00 の足がある日にしか発注しません。バックテストは 9:00 の足がない日数を注意として出します。
- 取得できる期間は、1分足が直近7日、5分足・15分足が直近60日までです。
- 呼値の刻みは銘柄で違います。TOPIX500 構成銘柄は `fineTickSymbols` に入れてください（例：3,000円超〜10,000円は通常5円または10円刻み、TOPIX500 は1円刻み）。設定が合っていないと滑りと損切り幅がずれるので、バックテストは刻みが合わないときに注意を出します。
- 祝日の判定はしていません。足が来なければ何もしません。安寄り買いは、10:00 を過ぎても1銘柄も寄り付いていない日を休場とみなし、株価の取得を1分に1銘柄に減らします。
