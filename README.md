# デイトレ検証

月間でプラスになるかを確かめる、株デイトレードの検証アプリです。過去データでのバックテストと、実際の値動きを使った仮想売買（ペーパートレード）ができます。**実際の発注は行いません。**

> 利益を保証するものではありません。バックテストやペーパートレードの成績が良くても、実際の取引で同じ結果になるとは限りません。

## 主な機能

- **バックテスト**：過去の分足で戦略を走らせ、日次損益、目標達成日数、勝率、最大ドローダウンなどを出します。
- **ペーパートレード**：場中に毎分動き、新しく確定した1分足で仮想売買して結果を記録します。
- **安全ルール**：日次損失上限で停止、取引回数の上限、大引け前の強制決済、同時保有は1ポジションまで（持ち越しの戦略を選んだときだけ、大引けで買って翌朝まで持ちます）。
- **画面**：今月の損益、今日の損益、月次・日次損益、取引履歴、バックテストの実行、開始・停止。

Node.js 22 以上が必要です。

```bash
npm install
npm run db:migrate:local
npm run dev            # http://localhost:8787
```

## 使い方

### コマンドラインでバックテスト

```bash
npm run backtest -- 7203                                  # 5分足 × 60日、寄り付きレンジ突破
npm run backtest -- 7203 --strategy vwap --slippage 0
npm run backtest -- 7203 --interval 1m --range 7d
npm run backtest -- 7203 --strategy gapfade --loss-limit 3000   # 戦略は orb / vwap / momentum / gapfade / pullback
npm run backtest -- 7203 --entry limit --limit-wait 3     # 新規を指値にする
npm run backtest -- 7203 --synthetic                      # 合成データ（動作確認用）
```

### 安寄り買い（`gapopen`）

前日終値より1%以上安く寄った銘柄を寄り付き（寄成）で買い、寄り値から0.5%下げたら損切り、そうでなければ大引け（引成）で売ります。日足10年分の検証で、前半・後半とも優位性が残った唯一のルールです。

寄り付きと大引けの値は分足に入っていない日が多いので、この戦略だけは日足の値（始値・安値・終値）で動きます。バックテストは日足で行い、ペーパートレードも当日の日足を毎分取りにいって、寄り付きでの買い、安値での損切り、大引けでの決済を判定します。対象銘柄のうち条件に合うものが複数あれば、ギャップが最も大きい1銘柄だけを買います。

```bash
npm run backtest -- 7203,6758,8306 --strategy gapopen --loss-limit 3000      # 日足 × 10年
npm run backtest -- core --strategy gapopen --loss-limit 3000 --max-position 500000  # 既定の50銘柄（wide で他の約200銘柄、all で両方）
```

実際の取引と違う点があります。寄り値は寄り付くまで分からないので、実際には寄り前の気配で「1%以上安く寄るか」を判断することになり、外れる日があります。急落時の損切りは1ティックより大きく滑ることがあります。

### 上げた日の持ち越し（`overnight`）

場中（始値から終値）に2%以上上げた銘柄のうち、最も上げた1銘柄を大引け（引成）で買い、翌営業日の寄り付き（寄成）で売ります。日足10年分の検証では、株の値上がりは場中ではなく夜間に集中していて、上げた日の翌朝はとくにその傾向が強く出ました。

デイトレではなく、夜間に持ち越します。**損切りは置けません。**夜間に悪材料が出ると翌朝の寄り付きでそのまま損になるので、`overnightMaxPositionYen` で買付金額を小さく抑えてください。1日の損失上限は損切りには効きませんが、翌朝の決済で上限を超える損が出た日は、その日の新規の買いを止めます。配当落ち日をまたいだときは、配当を損益に含めます。

`gapopen_overnight` にすると、安寄り買い（9:00〜15:30）と持ち越し（15:30〜翌9:00）の両方を動かします。持つ時間が重ならないので、同時に持つのは1ポジションのままです。

```bash
npm run backtest -- core --strategy overnight --overnight-max-position 300000
npm run backtest -- core --strategy gapopen_overnight --loss-limit 3000 --max-position 500000 --overnight-max-position 300000
```

実際の取引と違う点があります。引成の注文は大引けの前に出すので、「2%以上上げたか」の判断は 15:20 ごろの値で行うことになります。検証とペーパートレードは確定した終値で判断しています。決算発表の日をまたぐかどうかは見ていません。

### 銘柄選びの検証

複数銘柄でバックテストを回し、寄り付きレンジが確定した時点で分かる指標（ギャップ、出来高比、レンジ値幅など）とその日の損益の関係を集計します。境界は期間の前半で3等分して決め、後半にもそのまま当てはめるので、指標の選別力が続くかどうかを見られます。

```bash
npm run screen                                    # 既定の50銘柄、5分足 × 60日、寄り付きレンジ突破
npm run screen -- --symbols 7203,6758,9984        # 銘柄を指定
npm run screen -- --loss-limit 3000 --max-stop-fit 1   # 損切りが損失枠で狭められる日を集計から外す
npm run screen -- --cache .cache --csv out.csv    # 取得した足を保存して再利用、銘柄×日の明細を書き出す
```

既定の銘柄はすべて TOPIX500 構成銘柄（細かい呼値）として計算します。株価が呼値の刻みに乗らない日（株式分割より前の調整済みの値など）は自動で除きます。

### ギャップ埋めを日足で検証

分足は60日分しか取れないので、ギャップ埋め（安く寄った日に始値で買い、前日終値への戻りを狙う）は日足で10年分を検証できます。同じ日の取引は連動するので、日ごとにまとめた平均と t 値も出します。

```bash
npm run gapstudy                          # 既定の50銘柄、10年、ギャップ1%以上
npm run gapstudy -- --range 5y --gap 2 --slippage 0
```

### 日足でルールをまとめて検証

前日までの日足と当日の始値だけで入るかどうかが決まり、当日の終値で手仕舞うルールを、10年分の日足でまとめて試します（安く寄った日の買い、前日の急落後の買い、前日高値・安値の突破、前日安値への指値買いなど）。多くのルールを一度に試すとどれかは偶然よく見えるので、期間を前半と後半に分け、両方で t 値が大きいものだけを見ます。

```bash
npm run dailystudy                         # 既定の50銘柄、10年
npm run dailystudy -- --universe wide      # それ以外の東証プライムの主な約210銘柄（all で両方）
npm run dailystudy -- --detail fade-low    # 1つのルールを年ごと、相場全体の寄り付き別、月次で見る
npm run dailystudy -- --split 2020 --notional 500000
```

「持ち越し」と付くルールは、大引けで買って翌朝の寄り付きで売ります（デイトレではなく、夜間の値動きを取りにいく形）。買う日の終値までの情報だけで判断します。

寄り付きと大引けは成行（寄成・引成）で板寄せの値段で約定するとみなし、滑りを加えません。逆指値で入るルールは滑りを1ティック加え、指値で入るルールは値が指値を1ティック以上抜けた日だけ約定とします。

`--detail` では損切り（約定値から 0.5〜3%）を入れた場合と、1日1銘柄だけ取引したときの月次の試算も出します。寄り付きや指値で入るルールは、約定が必ずその日の安値より前なので、日足でも損切りを正しく判定できます。

「前日安値に指値で買い」は、日足で数えた約定が5分足でも確認できるか、約定の時刻や順番で成績が変わるかを直近60日で確かめられます。

```bash
npm run fadecheck
```

### ペーパートレード

画面の「開始する」を押すか `POST /api/bot/start` を呼ぶと、平日 9:00〜16:59（JST）に毎分動きます。対象銘柄や金額は `PUT /api/settings` で変えます。

### API

| エンドポイント | 内容 |
| --- | --- |
| `GET /api/status` | 今日と今月の損益、稼働状態、保有ポジション |
| `GET /api/positions` | 保有中のポジション |
| `GET /api/trades?date=YYYY-MM-DD` | 取引履歴（日付なしで直近200件） |
| `GET /api/pnl/daily` | 日次損益 |
| `GET /api/pnl/monthly` | 月次損益 |
| `GET /api/settings`、`PUT /api/settings` | 設定の取得と部分更新 |
| `POST /api/bot/start`、`POST /api/bot/stop` | ペーパートレードの開始と停止 |
| `POST /api/paper/tick` | 定期実行と同じ処理を手動で1回動かす |
| `POST /api/backtest` | バックテスト。`{ "symbol": "7203", "interval": "5m", "range": "60d", "settings": { ... } }` |

`API_TOKEN` を設定すると、GET 以外は `Authorization: Bearer <token>` が必要になります。

### 設定項目

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| `symbols` | `["7203.T"]` | 対象銘柄（最大20） |
| `fineTickSymbols` | `["7203.T"]` | 細かい呼値で取引される銘柄（TOPIX500 構成銘柄）。ここにない銘柄は通常の呼値で計算する |
| `strategy` | `orb` | `orb`（寄り付きレンジ突破）、`vwap`（VWAP逆張り）、`momentum`（後場順張り）、`gapfade`（ギャップ埋め）、`pullback`（VWAP押し目買い）、`gapopen`（安寄り買い）、`overnight`（上げた日の持ち越し）、`gapopen_overnight`（その両方）。後ろの3つは下の説明を参照 |
| `shares` | 100 | 1回の株数 |
| `dailyTargetYen` | 0 | 確定益がこの額に届いたらその日は終了。0 なら利益の上限なし |
| `dailyLossLimitYen` | 1000 | 確定損がこの額に届いたらその日は終了。損切り幅もこの枠に収まるよう狭める |
| `maxTradesPerDay` | 3 | 1日の取引回数の上限 |
| `slippageTicks` | 1 | 成行注文に加える不利な滑り（ティック数） |
| `commissionPerOrderYen` | 0 | 1注文あたりの手数料 |
| `entryOrder`、`limitWaitBars` | `market`、3 | 新規の出し方（`market` は成行、`limit` は指値）、指値が約定しないとき何本の足で取り消すか |
| `allowShort` | false | 空売りを使うか |
| `noEntryAfter` | 14:30 | これ以降は新規発注しない |
| `forceCloseAt` | 15:20 | これ以降の足の始値で強制決済する |
| `orbMinutes`、`orbRewardRisk` | 15、1 | レンジの長さ（分）、損切り幅に対する利確幅の倍率 |
| `vwapK`、`vwapMinBars` | 2、12 | 逆張りする乖離（標準偏差の倍数）、判定に必要な足数 |
| `momMinPct` | 0.5 | 後場順張りで入るのに必要な前場の騰落率（%） |
| `gapMinPct` | 1 | ギャップ埋め・安寄り買いで入るのに必要な前日終値からのギャップ（%） |
| `gapStopPct` | 0.5 | 安寄り買いで、寄り値から何%下げたら損切りするか |
| `maxPositionYen` | 0 | 安寄り買いで、1回の買付金額（株価×株数）がこれを超える銘柄を見送る。0 なら上限なし |
| `overnightMinPct` | 2 | 持ち越しで、場中（始値から終値）に何%以上上げた銘柄を買うか |
| `overnightMaxPositionYen` | 0 | 持ち越しの1回の買付金額の上限。0 なら `maxPositionYen` と同じ |

## 約定の考え方

バックテストとペーパートレードは同じエンジン（`src/core/engine.ts`）を使います。

- シグナルは足の確定時に出て、**次の足の始値**で約定します。未来の値は見ません。
- 損切りと利確は足の高値・安値で判定します。同じ足で両方に届いたときは損切りを優先します。
- 新規・損切り・強制決済は成行として滑りを加えます。利確は指値として滑りなしです。
- `entryOrder` を `limit` にすると、新規はシグナルが出た足の終値に指値を置きます。以降の足がその値を1ティックでも抜けたら指値の値段で約定とみなし、同値に触れただけでは約定としません。約定した足では利確を判定しません。
- 板の厚さや約定の順番待ちは再現していません。実際より有利に出ることがあります。

## 注意点

- 株価は Yahoo Finance の非公式APIから取ります。東証の値は約20分遅れで、予告なく使えなくなることがあります。ペーパートレードは遅れた足を順に処理するので、結果は記録として正しくても表示は約20分遅れます。
- Yahoo Finance の5分足は、9:00〜9:05 の足と 15:25〜15:30 の足が欠けている日が多くあります（9:00 の足があるのは主に週の最初の営業日）。欠けた日は寄り付きと大引けの値が分からず、寄り付きレンジは 9:05 からの足で作られます。`gapfade` は 9:00 の足がある日にしか発注しません。バックテストは 9:00 の足がない日数を注意として出します。
- 取得できる期間は、1分足が直近7日、5分足・15分足が直近60日までです。
- 呼値の刻みは銘柄で違います。TOPIX500 構成銘柄は `fineTickSymbols` に入れてください（例：3,000円超〜10,000円は通常5円または10円刻み、TOPIX500 は1円刻み）。設定が合っていないと滑りと損切り幅がずれるので、バックテストは刻みが合わないときに注意を出します。
- 祝日の判定はしていません。足が来なければ何もしません。
