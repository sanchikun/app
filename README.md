# リングタイマー

声で操作でき、声で知らせてくれる、円グラフ型のタイマー / インターバルタイマーです。
まずは Web アプリ（PWA）として試作し、最終的にはスマホアプリ化を目指しています。

## 概要

公開版: https://sanchikun.github.io/app/ （スマホで開いて「ホーム画面に追加」するとアプリのように使えます）

料理・筋トレ・ストレッチ・作業中など、手が離せない場面で使うことを想定したタイマーです。

- 画面を見なくても、**声で「3分タイマー」「ストップ」「残りは？」** と操作できます。
- 残り時間や区間の切り替えを **音声で読み上げ** ます。
- 画面を見れば、**設定した時間でちょうど1周するリング（円グラフ）** で残りがひと目でわかります。

アイデアの一覧や設計方針、スマホアプリ化の計画は [docs/IDEAS.md](docs/IDEAS.md) にまとめています。

## 主な機能

- **タイマー**: 分・秒で設定、クイック設定（1/3/5/10/15/30分）、開始・一時停止・リセット、+1分延長
- **インターバル**: 「1分 → 30秒 → 1分…」のようなワーク/休憩の繰り返し。3つ以上のステップ、準備カウント、最終休憩の省略、プリセット保存（タバタ・ポモドーロなどを内蔵）
- **音声で操作**（マイクボタンをオン）
  - 「3分タイマー」「1分半」「5分にセットして」
  - 「スタート」「ストップ」「再開」「リセット」「次」「戻って」
  - 「残りは？」「あと何分？」
  - 「1分追加」「30秒延長」
  - 「1分と30秒のインターバル 5回」「ワーク40秒 休憩20秒 8セット」
- **音声で報告**: 開始・区間の切り替え、残り1分 / 30秒 / 10秒、3・2・1 カウントダウン、終了（項目ごとにオン/オフ可）
- **円グラフで操作**: 止まっているときはダイヤルが設定画面になり、円をなぞる／ハンドルを回して時間を設定。インターバルは1ラウンドを扇形で表示し、各扇形のハンドルを回して区間の長さを設定
- **1周の範囲を選べる**（インターバル）: 「N回ごと」= Nラウンドで1周（初期値は1回ごと）/ 「全体」= インターバルを挟んだ全体で1周 / 「区間ごと」= ワーク・休憩それぞれで1周。編集バーの「1周」ボタンで切り替え、詳細（⋯）で回数を指定
- **円グラフ UI**: 動作中は「1周」の範囲でちょうど1周し、中の区間を色分けした扇形で表示。「リング」「パイ」の2スタイル、ワーク/休憩で色分け、外周に全体の進み具合
- **1画面で完結**: スクロールなし。プリセット・詳細編集・設定は下から出るシート
- 効果音・バイブレーション、動作中の画面スリープ防止、PWA（ホーム画面に追加・オフライン起動）

## 必要な環境

- Node.js 20 以上
- npm 10 以上
- 音声認識を使う場合: Chrome / Edge / Safari（Firefox は読み上げのみ対応）

## セットアップ

```bash
git clone https://github.com/sanchikun/app.git
cd app
npm install
```

## 使い方

```bash
# 開発サーバーを起動 → http://localhost:5173
npm run dev

# スマホ実機で試す（同じ Wi-Fi 内の端末からアクセス）
npm run dev -- --host

# 本番ビルド（dist/ に出力。静的ホスティングにそのまま置けます）
npm run build
npm run preview
```

> 音声認識（マイク）は `localhost` か HTTPS でのみ動作します。スマホ実機で音声操作を試すときは、
> HTTPS のホスティング（GitHub Pages / Cloudflare Pages など）に `dist/` を置くのが簡単です。

基本操作:

1. 上の切り替えで「タイマー」か「インターバル」を選ぶ
2. ダイヤルの円をなぞって時間を設定（下の −/＋ やクイックボタンでも調整可）
   - インターバル: 扇形をタップして区間を選び、その扇形の端のハンドルを回す。選択中の区間ボタンをもう一度押すとワーク/休憩が切り替わる。「⋯」で区間の追加・名前・準備時間など
3. ダイヤル中央か ▶ をタップして開始
4. 左上のマイクボタンをオンにすると、声で操作できます

PC ではキーボードも使えます: `Space` 開始/一時停止、`R` リセット、`←` / `→` 前/次の区間。

## ディレクトリ構成

```
app/
├── docs/IDEAS.md          # アイデア一覧・設計方針・スマホアプリ化ロードマップ
├── public/                # PWA マニフェスト・アイコン・Service Worker
├── src/
│   ├── core/              # ブラウザに依存しないロジック（スマホアプリでも再利用）
│   │   ├── program.ts     #   タイマー/インターバルの定義と区間への展開
│   │   ├── engine.ts      #   経過時間ベースのタイマーエンジン
│   │   ├── announcer.ts   #   いつ何を知らせるかの判定（純粋関数）
│   │   ├── format.ts      #   表示・読み上げ文の生成
│   │   └── voiceCommands.ts # 音声認識の文字列 → コマンド変換
│   ├── services/          # プラットフォーム依存部分（読み上げ・音声認識・効果音・保存など）
│   ├── hooks/useTimer.ts  # エンジンを React で使うためのフック
│   ├── components/        # ダイヤル・操作ボタン・設定パネルなどの UI
│   └── App.tsx
└── tests/                 # ユニットテスト
```
